# gsp-csice-research
GSP Research, recreating Blind Deconvolution of Nonstationary Graph Signal over Shift-Invariant Channels (Zare et al., 2025) + expansions

## Computational Execution

The numerical experiments, partial observation sweeps, and signal recovery trials in this repository WILL be executed on Michigan State University's High-Performance Computing Cluster (HPCC) due to the high sample complexity and matrix decompositions involved. Keep your eyes peeled

- Pre-Rendered Visualizations: All `.ipynb` notebooks in this repository contain pre-computed outputs so they can be viewed directly on GitHub without re-running long execution jobs locally.
